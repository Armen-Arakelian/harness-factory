# Contributing

Fork this public repository, create a branch and open a pull request against `main`. Describe the problem, the resulting behavior and the checks you ran. Run `python3 .agents/skills/update-factory/scripts/check_factory.py` for blueprint or generator changes.

The repository owner, @Armen-Arakelian, reviews contributions and is the sole required code owner. Main requires a pull request, passing generator CI, an up-to-date branch and resolved review threads. New commits dismiss previous approvals. Contributors do not need write access to submit a PR from their fork.

The owner may merge their own PR without another person's approval, since GitHub prevents self-approval. That exception applies only to the review requirement through a PR; it never bypasses CI or permits direct pushes, force pushes or deletion of main. Agent-driven merges still require an explicit user request.
